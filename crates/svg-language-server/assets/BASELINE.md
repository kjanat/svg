# Baseline artwork

The six `baseline-*-icon*.svg` files are unmodified upstream assets from
[WebDX's official logo downloads](https://web-platform-dx.github.io/name-and-logo-usage-guidelines/).

this crate's MIT-licensed code. No Google sponsorship or endorsement is implied.

`baseline-icons.json` records the canonical repository, immutable revision,
source directory, and SHA-256 of every file. These files are the single vendored
source; `workers/svg-compat/static/badges/` contains generated byte-for-byte
copies. Do not change colors, paths, whitespace, or add comments inside the
SVGs.

| Web Features status     | Asset family            | Presentation                                            |
| ----------------------- | ----------------------- | ------------------------------------------------------- |
| `"high"`                | `baseline-widely-icon`  | Widely Available; also usable for Baseline as a concept |
| `"low"`                 | `baseline-newly-icon`   | Newly Available                                         |
| `false`                 | `baseline-limited-icon` | Limited availability / non-Baseline                     |
| Missing or unrecognized | None                    | Neutral text or omission                                |
| WebDX discouragement    | None by default         | Explain the advice, references, and alternatives        |

Use `-dark.svg` for a dark background and `.svg` for a light background. Select
variants and scale proportionally in the display code. The dashboard uses
`picture`; the LSP uses an SVG container with embedded, unchanged images and a
theme media query. Neither changes the artwork. Clients without theme
media-query support use the light variant.

## Updating

From the repository root:

1. Select an immutable revision of
   [the official website repository](https://github.com/web-platform-dx/web-platform-dx.github.io).
   Review its logo guidelines and download all six files from `src/assets/img/`
   as raw bytes into this directory.
2. Update the revision and hashes in `baseline-icons.json` after verifying their
   origin. Do not optimize, minify, reformat, or redraw the images.
3. Run `just baseline-icons-sync` to replace the worker copies.
4. Run `just baseline-icons-upstream` to compare both local sets with that
   pinned upstream revision, then `just verify` and inspect both themes.

`just baseline-icons-check` performs the normal offline hash/copy check and is
part of preflight and CI. Git attributes prevent newline conversion.
